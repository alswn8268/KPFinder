# AI 폴더 정리 도우미

> 2026년 사내 AX 과제 해결 공모전 출품작 — 어질러진 업무 폴더를 스캔해서 AI가 더 깔끔한 폴더 구조를
> **제안**하는 로컬 실행 도구입니다. **AI는 절대 자동으로 파일을 옮기지 않습니다.**
> 항상 **스캔 → AI 제안 → 사람이 확인 → 적용** 순서를 따릅니다.

## 핵심 원칙

- 완전 로컬 실행: 인터넷 연결 없이 [Ollama](https://ollama.com) 로컬 LLM(`exaone3.5:2.4b`)만 사용합니다.
  외부 API 호출이 전혀 없어 민감한 사내 문서가 외부로 나가지 않습니다.
- **미리보기 우선**: '적용' 버튼을 누르기 전까지 원본 폴더의 어떤 파일도 이동·수정·삭제되지 않습니다.
- **되돌리기 가능**: 실제로 파일을 이동하면 이동 기록이 남고, 언제든 되돌릴 수 있습니다.

## 준비물

1. Python 3.10 이상
2. [Ollama](https://ollama.com) 설치 후 모델 다운로드 (최초 1회, 약 1.6GB)

   ```bash
   ollama pull exaone3.5:2.4b
   ollama serve   # 이미 실행 중이면 생략 가능
   ```

3. 파이썬 패키지 설치

   ```bash
   pip install -r requirements.txt
   ```

## 실행

```bash
streamlit run streamlit_app.py
```

브라우저에 열리는 화면에서:

1. **정리할 폴더 경로**를 입력하고 **① 스캔** — 파일 목록과 완전 중복 파일이 즉시 표시됩니다 (해시 비교라 빠릅니다).
2. **② AI 분석** — 파일별 1~2문장 요약과 제안 폴더 구조를 생성합니다. GPU 없는 PC에서는
   문단 하나당 약 40~80초가 걸릴 수 있으니, 시연 직전에 미리 한 번 돌려서 캐시해 두는 것을 권장합니다.
   (동일한 파일은 캐시되어 재분석 시 즉시 결과가 나옵니다.)
3. **Before/After 트리 비교**를 확인하고, 필요하면 리포트를 JSON으로 다운로드합니다.
4. 계획을 확인하고 동의 체크 후 **🚀 적용**을 누르면 실제로 파일이 이동합니다.
   문제가 있으면 사이드바의 **실행 취소**로 즉시 되돌릴 수 있습니다.

## 데모용 샘플 폴더 만들기

이름 규칙이 제각각인 문서 30여 개와 완전 중복 파일 4개를 포함한 어질러진 폴더를 생성합니다.

```bash
python sample_data/generate_sample_data.py
# 기본 출력 위치: sample_data/messy_folder
```

## 프로젝트 구조

```
streamlit_app.py          # Streamlit UI (스캔 -> AI 분석 -> 비교 -> 적용)
app/
  scanner.py               # 폴더 스캔, 해시 기반 완전 중복 탐지
  text_extractor.py         # .txt/.docx/.xlsx/.csv/.pptx/.pdf 텍스트 추출
  llm_client.py             # Ollama 로컬 LLM 연동 (요약, 폴더 구조 제안)
  organizer.py              # 요약 오케스트레이션 + 캐싱, assignments 검증
  similar.py                # 유사 문서(버전 다른 파일) 탐지 (difflib 기반)
  file_ops.py               # 이동 계획 생성, 실제 적용, 되돌리기(undo)
  report.py                 # Before/After 트리 렌더링, 다운로드용 리포트
sample_data/
  generate_sample_data.py   # 데모용 샘플 폴더 생성 스크립트
tests/                      # pytest 단위 테스트 (Ollama 없이 실행 가능)
```

## 테스트

Ollama 연결이 필요 없는 핵심 로직(스캔, 중복/유사 문서 탐지, 이동/되돌리기, 트리 렌더링)은
단위 테스트로 검증되어 있습니다.

```bash
pip install -r requirements-dev.txt
pytest
```

## v1 범위 제외 (Non-Goals)

과욕은 이 프로젝트의 가장 큰 리스크이기 때문에 아래 항목은 의도적으로 제외했습니다.

| 제외 항목 | 이유 |
|---|---|
| AI가 자동으로 파일을 이동·삭제 | 오작동 시 실제 업무 파일 손상 리스크. 반드시 사람 승인 후에만 실행 |
| `.hwp`/`.hwpx` 본문 텍스트 지원 | 텍스트 추출 난이도가 매우 높음. v1은 `.txt/.docx/.xlsx/.csv/.pptx/.pdf`로 한정 |
| 실시간 폴더 감시/자동화 | 데모용 온디맨드(버튼 클릭) 스캔으로 충분 |
| 다중 사용자 동시 접속/권한 관리 | 1인 시연용 로컬 도구로 시작 |
| 클라우드 동기화, 외부 API 연동 | 사내 보안 정책상 금지. 전부 로컬 처리 |

## 알려진 제한사항

- 폴더 구조 제안은 로컬 소형 모델(`exaone3.5:2.4b`)이 생성하므로, 파일 수가 많거나 내용이
  복잡할 경우 제안 품질이 사람이 정리한 것만큼 정교하지 않을 수 있습니다. 최종 판단은 항상 사람이 합니다.
- 완전 중복 파일 그룹에서 어떤 파일을 남기고 어떤 파일을 삭제할지는 자동으로 결정하지 않으며,
  중복 목록만 보여줍니다 (삭제는 v1 범위 밖).
- 유사 문서 탐지는 임베딩 모델 없이 파일명·요약 문자열 유사도(`difflib`)로 가볍게 판별하므로
  완벽하지 않은 휴리스틱입니다.
